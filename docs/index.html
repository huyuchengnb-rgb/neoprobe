关于 NeoProbe 网页版

数据来源

1. 回合阶段 / 剩余局数 / 倒计时：浏览器每 10 秒直接请求 status.php，按 server_time - updated_at 补偿后本地每秒走秒。目前仅收录 202.189.21.228 上的 3 台测试服与兑换服；6 台 mio 正式服未上报，显示「未上报」。

2. 服务器在线 / 人数 / 地图 / 玩家 / 规则：由 GitHub Actions 定时运行 A2S UDP 查询并发布到静态 data/state.json（约每 5–15 分钟更新一轮）。

3. 一键进服：调用 steam://connect/ip:port 拉起本机 Steam 连接 Garry's Mod。

桌面版独有功能：本机实时 15s UDP A2S、本机真实 RTT、满员自动挤服、本机 Steam VIP 读取。可在仓库运行 python -m neoprobe --serve 或下载 NeoProbe.exe。
